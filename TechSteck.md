# Технологический стек проекта: Анализатор фондовых стратегий

Этот документ описывает технологии, которые мы используем для создания нашего веб-приложения. Описание составлено просто и понятно, чтобы любой новый разработчик мог быстро вникнуть в суть.

## 1. Основа приложения (Каркас)
* **React**
  * *Что это:* Библиотека для создания пользовательских интерфейсов.
  * *Зачем:* Позволяет собирать интерфейс приложения как из кубиков Lego (компонентов). Например, кнопка, график, таблица — это отдельные "кубики", которые легко переиспользовать.
* **TypeScript**
  * *Что это:* Тот же JavaScript, но со строгими правилами (типизацией).
  * *Зачем:* Работает как продвинутая проверка орфографии для кода. В финансовом приложении много расчетов и сложных данных (цены, проценты, даты). TypeScript не даст случайно сложить текст с числом и покажет ошибку еще до запуска программы.
* **Vite**
  * *Что это:* Сборщик проекта.
  * *Зачем:* Он берет весь наш код и мгновенно превращает его в готовый сайт. Делает разработку очень быстрой: вы меняете код, и страница в браузере обновляется за долю секунды.

## 2. PWA (Progressive Web App) и Оффлайн-режим
* **vite-plugin-pwa (Workbox)**
  * *Что это:* Инструмент, который превращает обычный сайт в полноценное приложение.
  * *Зачем:* Благодаря ему пользователь может зайти на наш сайт и нажать "Добавить на главный экран". На телефоне появится иконка, как у обычного приложения. Плагин также сохраняет (кэширует) все картинки, кнопки и скрипты в память устройства, чтобы приложение открывалось мгновенно даже без интернета.

## 3. Работа с данными и API (Интернет-запросы)
* **fetch**
  * *Что это:* Встроенная в браузер команда для скачивания данных из интернета.
  * *Зачем:* Чтобы получать актуальные цены акций и дивиденды напрямую с серверов Московской Биржи.
* **TanStack Query (React Query)**
  * *Что это:* Умный менеджер запросов к серверу.
  * *Зачем:* Работает как умный библиотекарь. Если мы один раз запросили цену акций "Сбербанка" за 2023 год, он запомнит ее. Если другой компонент снова попросит эти данные, React Query отдаст их из памяти мгновенно, не делая лишний запрос в интернет.

## 4. Локальная база данных (Память приложения)
* **IndexedDB + Dexie.js**
  * *Что это:* Встроенная в браузер база данных (IndexedDB) и удобная библиотека для работы с ней (Dexie.js).
  * *Зачем:* История котировок (свечи по дням за несколько лет) весит очень много. Мы не можем хранить её в обычной памяти браузера. Dexie.js позволяет надежно хранить гигабайты исторических данных прямо на устройстве пользователя.
* **Zustand**
  * *Что это:* Легковесный менеджер глобального состояния.
  * *Зачем:* Это "кратковременная память" интерфейса. Он запоминает, какую вкладку открыл пользователь, какой портфель сейчас выбран и включена ли темная тема.

## 5. Внешний вид (Дизайн)
* **Tailwind CSS**
  * *Что это:* Фреймворк для стилизации.
  * *Зачем:* Вместо того чтобы писать длинные CSS-файлы, мы стилизуем элементы, добавляя им классы (например, `text-red-500` сделает текст красным). Это сильно ускоряет работу.
* **shadcn/ui**
  * *Что это:* Набор готовых красивых элементов интерфейса (выпадающие списки, окна, таблицы).
  * *Зачем:* Позволяет не изобретать велосипед. Мы берем готовый, красивый и удобный компонент, копируем его в проект и при необходимости легко меняем под свой дизайн.
* **Recharts**
  * *Что это:* Библиотека для рисования графиков.
  * *Зачем:* Чтобы красиво и наглядно рисовать линии доходности стратегий и сравнивать их с биржевыми индексами.

## 6. Работа с файлами (Сохранение стратегий)
* **JSON + Blob + File API**
  * *Что это:* Стандартные браузерные инструменты для работы с файлами.
  * *Зачем:* Все портфели пользователя превращаются в текстовый формат (JSON). Приложение умеет скачивать этот текст как обычный файл (экспорт) и читать такие файлы (импорт). Пользователь может скинуть этот файл другу в мессенджере, и друг откроет его в своем приложении. На современных компьютерах приложение сможет даже перезаписывать этот файл без постоянных скачиваний (через File System Access API).
