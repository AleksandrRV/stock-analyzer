# 04. Технологический стек

Ниже — технологии, фактически используемые в кодовой базе (см. `stock-analyzer/package.json`). Каждая сопровождается кратким объяснением «зачем она нужна», понятным новичку.

## Основа приложения (каркас)

| Технология | Что это | Зачем |
|---|---|---|
| **React 18** | Библиотека для построения интерфейсов | Собирать UI из переиспользуемых компонентов («кубиков»): кнопка, график, таблица |
| **TypeScript 5** (strict) | JavaScript со строгой типизацией | «Проверка орфографии» для кода: не даёт сложить текст с числом, ловит ошибки до запуска — критично для финансовых расчётов |
| **Vite 5** | Сборщик проекта | Мгновенно превращает код в готовый сайт; очень быстрая разработка с горячей перезагрузкой |

## Состояние приложения

| Технология | Что это | Зачем |
|---|---|---|
| **Zustand 5** | Лёгкий менеджер глобального состояния | «Кратковременная память» интерфейса: активная вкладка, выбранный портфель, тема, настройки, кэш расчётов |

Навигация между экранами (Дашборд → Портфель → Настройки) реализована на состоянии (без роутера).

## Хранение данных

| Технология | Что это | Зачем |
|---|---|---|
| **IndexedDB + Dexie.js 4** | Встроенная в браузер БД и удобная обёртка над ней | Хранить «тяжёлую» историю котировок (свечи за годы) прямо на устройстве |
| **localStorage** | Простое ключ-значение хранилище браузера | Хранить «лёгкие» пользовательские данные: портфели, группы, настройки |

## Визуализация и дизайн

| Технология | Что это | Зачем |
|---|---|---|
| **Tailwind CSS 3** | CSS-фреймворк на утилитарных классах | Стилизация прямо в разметке (`text-red-500` — красный текст); ускоряет работу |
| **Recharts 3** | Библиотека графиков | Рисовать кривые доходности стратегий и сравнивать их с индексами |
| **lucide-react** | Набор SVG-иконок | Единый стиль иконок в интерфейсе |

UI-компоненты написаны вручную поверх Tailwind (без внешней библиотеки компонентов).

## PWA и офлайн-режим

| Технология | Что это | Зачем |
|---|---|---|
| **vite-plugin-pwa (Workbox)** | Инструмент превращения сайта в приложение | Иконка «на главном экране», манифест, Service Worker, кэширование статики для мгновенного офлайн-открытия |

## Работа с сетью и файлами

| Технология | Что это | Зачем |
|---|---|---|
| **fetch** | Встроенный браузерный запрос | Получать цены и дивиденды напрямую с серверов Мосбиржи (`iss.moex.com`, CORS разрешён) |
| **JSON + Blob + File API** | Стандартные браузерные инструменты | Экспорт портфелей в JSON-файл и импорт обратно |
| **File System Access API** | API «тихой» перезаписи файлов (Chrome/Edge) | Перезапись открытого файла стратегии без повторных скачиваний |
