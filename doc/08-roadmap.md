# 08. План разработки (исторический срез)

План описывает **10 последовательных этапов** разработки по методологии **Vertical Slicing** («вертикальные срезы»): каждый этап завершается работоспособной версией, которую можно открыть в браузере и проверить вручную.

> Статус: по состоянию на версию **1.2.0** все 10 этапов реализованы. Документ сохранён как историческая справка о логике развития продукта; актуальный список незакрытых задач — в `09-known-issues.md`.

| Этап | Цель | Ключевой результат |
|---|---|---|
| **1. Каркас и PWA-оболочка** | Работающий заголовок с офлайн-поддержкой | Vite + React + TS + Tailwind; `vite-plugin-pwa` (manifest + Service Worker); шапка, переключатель темы, индикатор сети |
| **2. Ядро математики и локальная БД** | Изолированный «мозг» и хранение | Dexie.js + localStorage; `DateTimeStandardizer`; `FinancialMath` (сложный процент, CAGR, налог 15%); `TickerResolver` |
| **3. Интеграция с MOEX и кэширование** | Запросы к бирже и кэш | `MoexApiGateway`; `MarketDataSyncService` (Read-Through); `CalendarAdjuster` |
| **4. Портфели и группы (CRUD + Lazy Loading)** | Управление портфелями и папками | `PortfolioStore`; поштучное удаление с подтверждением; дашборд с табами; ленивая загрузка групп |
| **5. Редактор контрольных точек** | Сборка структуры портфеля по датам и часам | Milestone Editor: дата/час, активы с весами, индикатор свободного кэша, подсказки `TickerResolver` |
| **6. Расчёт показателей и цветовая индикация** | Первые реальные метрики | `TimelineEngine` + `FinancialMath`; доходность с LQDT и налогом; Альфа vs MCFTR; цветовая индикация карточек |
| **7. Интерактивный график доходности** | Визуализация роста капитала | Recharts; Equity Curve по контрольным точкам; две линии (Портфель vs MCFTR); фильтры периодов |
| **8. Матрица доходности по месяцам** | Помесячная статистика | Таблица «Год/Месяц»; цены на стыках месяцев; подсветка неполных месяцев |
| **9. Настройки, очистка кэша, экспорт/импорт** | Управление параметрами и перенос данных | Ставка налога и карта тикеров; гранулярная очистка кэша; `FilePortabilityService` (экспорт/импорт, File System Access API) |
| **10. Полировка и стресс-тесты** | Готовность к эксплуатации | Аудит офлайн-режима; Toast-уведомления об ошибках сети; адаптация под мобильные; проверка краевых кейсов |

## Проверочный сценарий каждого этапа

Каждый этап завершался ручной проверкой вида:
1. Открыть приложение в браузере и выполнить действия по этапу.
2. Убедиться в ожидаемом результате (например, 1% в месяц = 12.68% годовых; индикатор свободной доли показывает 20% при 40%+40%; удаление требует подтверждения).
3. Проверить поведение в офлайн-режиме (данные берутся из кэша, а не из сети).
