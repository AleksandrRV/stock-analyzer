# 06. Бизнес-логика и финансовая математика

## Контрольные точки (Milestones) и жизненный цикл

- Точка действует **до наступления следующей по хронологии точки**, либо до **«Даты закрытия»** портфеля.
- Если портфель открыт и будущих точек нет, точка действует «до текущего момента» — её доходность пересчитывается каждый новый час.
- В точке задаются доли (веса) активов в процентах: акции и/или фонды.
  - **Акции (STOCK):** учитываются изменение цены + дивиденды.
  - **Фонды (FUND):** учитываются только по изменению цены (без дивидендов).
- Удаление портфелей — строго поштучно, с окном подтверждения (защита от случайного массового удаления).

## Свободный кэш (LQDT)

Если сумма долей активов меньше 100%, нераспределённый остаток («свободный кэш») не лежит мёртвым грузом: алгоритм **автоматически** начисляет на него доходность по историческим котировкам фонда денежного рынка **LQDT**.

## Сложный процент (геометрическая доходность)

Все среднемесячные и среднегодовые доходности считаются **строго по формулам сложного процента**, а не средним арифметическим.

- Накопленная доходность цепочки периодов: `∏(1 + rᵢ/100) − 1`.
- Пересчёт общей доходности за N дней в среднемесячную: месяцы = `N / 30.4375` (средняя длина месяца), затем корень соответствующей степени.
- Месячная → годовая: `(1 + r/100)¹² − 1`.
- **Пример:** 1% в месяц = **12.68%** годовых, а не 12.00%.

## Ключевая метрика — Альфа

Эффективность стратегии измеряется относительно индекса Мосбиржи полной доходности **MCFTR**:

```
Альфа = Среднемесячная доходность портфеля − Среднемесячная доходность MCFTR
```

(за строго идентичный период).

**Цветовая индикация карточек портфеля** на дашборде (по значению Альфы):

| Альфа | Цвет |
|---|---|
| < 0.01% | Красный |
| 0.01% – 0.9% | Жёлтый |
| > 0.9% | Зелёный |

## Учёт дивидендов

- **Принцип зачисления.** Для чистоты бэктеста дивиденд, очищенный от налога (по умолчанию **15%**), напрямую прибавляется к цене закрытия акции в конце контрольного периода.
- **Условие зачёта.** Дивиденд засчитывается точке, если дата отсечки наступила **строго после** старта точки и **до/включительно** её финиша.
- **Формула профита акции:** `((priceFinish + чистыеДивиденды − priceStart) / priceStart) × 100`, где чистые дивиденды = сумма × (1 − налог/100).
- **Защита от валютных дубликатов (ГДР).** API Мосбиржи отдаёт дивиденды компаний с депозитарными расписками (например, MGNT, ROSN) сразу в двух валютах. Жёсткий фильтр `RUB | SUR | RUR` отбрасывает дубликаты, чтобы доходность не удваивалась.
- **Сплиты акций.** Учитываются через справочник коэффициентов (см. ниже). Ручной контроль также возможен через настройки.

### Ручной ввод дивидендов и авто-сверка

Раскрытие дивидендов в API Мосбиржи часто задерживается на недели, поэтому реализован ручной ввод:

1. Записи помечаются флагом `isManual: true` в локальной БД.
2. При ручном добавлении проверяется окно **±30 дней**: если выплата там уже есть — ввод блокируется.
3. Когда официальные данные появляются в API MOEX, система находит ручные записи в окне ±30 дней и **автоматически заменяет их** на верифицированные.
4. Дополнительный резервный источник — **SmartLab** (парсинг страницы дивидендов через CORS-прокси).

## Корпоративные события: сплиты и смена тикеров

### Машина времени тикеров (Ticker Resolver)

На рынке происходят переименования тикеров (редомициляция). Если запросить старый тикер за новую дату — биржа вернёт ошибку («тикер мёртв»), и наоборот.

**Решение:** в проект зашит справочник переименований (`DEFAULT_TICKER_RENAMES`), например `TCSG → T`, `YNDX → YDEX`, `FIVE → X5`, `MAIL → VKCO`. Алгоритм подставляет нужный тикер в зависимости от даты запроса; в интерфейсе старые тикеры подсвечиваются подсказкой вида `(TCSG → T)`. Пользователь может добавлять собственные правила в настройках.

### Сплиты в «размерности сегодняшнего дня»

**Особенность MOEX:** биржа задним числом корректирует графики «живых» тикеров под сплиты, но оставляет без изменений графики «мёртвых» тикеров.

*Пример:* из-за сплита 1:10 текущая цена T-Банка (`T`) ~300 ₽, и историческую цену за 2023 год MOEX отдаёт скорректированной (~300 ₽). Но старый тикер `TCSG` за 2023 год отдаётся как есть — 3000 ₽. Прямое сравнение дало бы ложный убыток −90%.

**Решение:** алгоритм приводит старые цены к «размерности сегодняшнего дня» — находит все сплиты «наследников» и делит старую цену на их коэффициенты (3000 / 10 = 300). Дивиденды делятся так же, чтобы доходность сходилась копейка в копейку. Справочник `DEFAULT_STOCK_SPLITS` пополняется пользователем.

## Время, часовые пояса и календарь

### Треугольник часовых поясов

Часовые пояса — частая причина багов, поэтому принят жёсткий стандарт:

1. **Пользовательский ввод (UI):** строго в локальном времени устройства.
2. **База данных (IndexedDB / JSON):** строго в ISO **UTC**.
3. **Запросы к MOEX API:** строго в **MSK** (UTC+3) — биржа живёт по московскому времени.

Точность контрольных точек обрезается до часа (минуты и секунды = `00:00`).

### Обработка неторговых дней

- Если контрольная точка или конец месяца выпадает на выходной/праздник, API вернёт пустоту.
- `CalendarAdjuster` запрашивает свечи с флагом `iss.reverse=true` и окном поиска на 7 дней назад — так гарантированно берётся последняя доступная цена закрытия (например, цена пятницы).
- При приостановке торгов/делистинге используется последняя известная цена, «протянутая» вперёд.
- Границы месяцев считаются в UTC-полдень (`12:00 UTC`), чтобы при переводе в MSK не происходило сдвига на следующий день.

## Бенчмарк и графики

- **Бенчмарк:** MCFTR (Индекс Мосбиржи полной доходности) за тот же период.
- **Кривая доходности (Equity Curve):** линейный график роста портфеля и бенчмарка, построенный **строго по контрольным точкам** (+ текущий день или дата закрытия). Промежуточные ежедневные колебания не загружаются — это снижает сетевую нагрузку.
- **Матрица доходности по месяцам:** сводная таблица результата по календарным месяцам; для расчёта запрашиваются цены на стыках месяцев; неполные месяцы (в начале/конце жизни портфеля) помечаются визуально.
- **Фильтры периодов графика:** 1М, 3М, 6М, 1 Год, YTD (с начала года), Всё время.
