# Анализатор фондовых стратегий (MOEX Strategy Analyzer) — Документация

Это центральный указатель пакета документации проекта. Документы написаны так, чтобы их понимал и новый участник команды, и опытный разработчик.

## О проекте в двух словах

**Анализатор фондовых стратегий** — кроссплатформенное веб-приложение (PWA) для бэктестинга и анализа портфельных стратегий на Московской бирже (MOEX). Работает прямо в браузере, устанавливается на устройство в один клик и полностью функционирует офлайн: все данные и расчёты хранятся и выполняются на устройстве пользователя.

| Параметр | Значение |
|---|---|
| Тип | Progressive Web App (PWA), чистый фронтенд, serverless |
| Язык | TypeScript (strict mode) |
| Ядро | React 18 + Vite 5 |
| Хранение | IndexedDB (Dexie.js) — рыночный кэш; localStorage — данные пользователя |
| Источник данных | API Московской биржи `iss.moex.com` |
| Деплой | GitHub Actions → GitHub Pages |
| Текущая версия | 1.2.0 |

## Как читать документацию

1. **Только знакомитесь с проектом** — начните с `01-product.md`, затем `02-getting-started.md`, чтобы запустить приложение.
2. **Собираетесь писать код** — прочитайте `03-architecture.md` и `05-data-model.md`, чтобы понять, где и как устроены данные и логика.
3. **Нужно разобраться в расчётах** — откройте `06-business-logic.md` (математика) и `07-performance.md` (кэши).
4. **Ищете, что доделать** — смотрите `09-known-issues.md`.

## Структура репозитория

```
stock-analyzer/          # Код приложения (Vite + React + TypeScript)
  src/
    components/          # UI-компоненты (слои Presentation)
    engine/              # Чистая математика и доменная логика (слой Domain)
    services/            # API-шлюзы, синхронизация, хранилища (Infrastructure + Application)
    store/               # Глобальное состояние (Zustand)
    db/                  # База рыночного кэша (IndexedDB / Dexie)
    types/               # Доменные типы (контракты данных)
    constants/           # Конфигурация, справочники тикеров и активов
  dist/                  # Собранная для публикации версия (результат npm run build)
doc/                     # Эта документация
.github/workflows/       # CI/CD (деплой на GitHub Pages)
```
