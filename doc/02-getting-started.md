# 02. Быстрый старт и сборка

## Требования

- **Node.js** версии LTS (CI-сборка использует Node 22). Вместе с Node.js устанавливается пакетный менеджер **npm**.
- Код проекта находится в подкаталоге **`stock-analyzer/`** — все команды ниже выполняются из него.

> Примечание для Windows (PowerShell): если команды `npm` не распознаются, убедитесь, что Node.js установлен и добавлен в `PATH`. Если запуск скриптов запрещён политикой выполнения, выполните `Set-ExecutionPolicy RemoteSigned -Scope CurrentUser`.

## Установка зависимостей

```bash
cd stock-analyzer
npm install
```

## Запуск в режиме разработки

```bash
npm run dev
```

Vite поднимет локальный сервер разработки (обычно `http://localhost:5173`) с горячей перезагрузкой: изменения кода мгновенно отображаются в браузере.

## Сборка production-версии

```bash
npm run build
```

Команда выполняет `tsc` (проверка типов) и `vite build`. Результат — статическая сборка в каталоге `stock-analyzer/dist/`.

Предпросмотр собранной версии локально:

```bash
npm run preview
```

## Линтинг

```bash
npm run lint
```

## Деплой

Деплой автоматизирован через GitHub Actions (`.github/workflows/deploy.yml`):

- триггер — `push` в ветку `main`;
- шаги: checkout → установка Node 22 → `npm ci` → `npm run build` → публикация каталога `dist/` на **GitHub Pages**.

Важно: в `vite.config.ts` задан `base: '/stock-analyzer/'`, поэтому приложение рассчитано на размещение по пути `/stock-analyzer/` на GitHub Pages. При смене хостинга этот параметр нужно обновить.

## Установка PWA

1. Откройте приложение в Chrome или Safari.
2. Нажмите «Установить приложение» / «Добавить на главный экран».
3. На телефоне (или рабочем столе Windows) появится иконка приложения, работающего в отдельном окне без адресной строки.

После установки приложение открывается мгновенно и работает офлайн — статика кэшируется Service Worker'ом (Workbox), а данные — в IndexedDB.

## Быстрая проверка офлайн-режима

1. Откройте приложение и создайте портфель с контрольной точкой.
2. Отключите интернет и обновите страницу — приложение должно открыться, а сохранённые данные и кэшированные котировки остаться доступными.
